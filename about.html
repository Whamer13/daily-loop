About Daily Loop.

Daily Loop is an independent directory designed to make it easier to find the little puzzle games people come back to every day.

What you'll find here

The directory brings together daily word games, geography challenges, number puzzles, trivia, film and music games, sport and gaming challenges, and nature-themed puzzles. Search by name or topic, filter by category, and save favourites in your browser.

We link out — we don't host the games

Each Play link opens the game on its own website. Daily Loop does not own, operate, reproduce or control those games. Game names, logos and other trademarks belong to their respective owners. A listing is not an endorsement, partnership or claim of affiliation.

Keeping the directory useful

Daily games sometimes change address, pause, or shut down. This is a curated starting list, not a guarantee that every daily game on the internet is included or that every third-party game will always be available. Links should be checked regularly and outdated listings removed.
